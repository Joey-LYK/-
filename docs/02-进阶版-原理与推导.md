## 第一章 最小化数学——为神经网络准备的微积分

> 核心思路：只学"用得到的那点微积分"，不追求数学的完备性。
> 如果你已经学过微积分，可以快速扫过这一章。

### M-01 导数的直觉

**导数 = 变化率 = 这一刻变多快**

想象你坐在车里看速度表：

```
时刻 1s：位置 10m  →  时刻 2s：位置 30m
变化率 = (30 - 10) / (2 - 1) = 20 m/s
```

这个"20 m/s"就是位置函数在 t=1.5s 附近的导数——**位置变化的速率**。

数学记法：

```
f(x) 在 x₀ 处的导数记作 f'(x₀)
含义：f 在 x₀ 附近每变化 1 个单位，f(x) 变化多少
```

**用图形理解**：

```
     ↑ f(x)
     │        *
     │       /  ← 切线的斜率就是 f'(x₀)
     │      /
     │     /
     │    /
     │   /
     │  /
     │ /
     │/
     └──────────→ x
        x₀
```

导数 = 切线的斜率 = 函数在该点的变化率。

**对神经网络的意义**：我们需要知道"损失函数对每个权重的变化率"，才能知道该把权重往哪个方向调、调多少。

> **检查点**：如果 f(x) = x²，在 x=3 处 f'(3) 是多少？（提示：斜率 = 6）

### M-02 常见函数的导数

神经网络里只需要记住三个导数结果：

**1. x² 的导数**

```
f(x) = x²
f'(x) = 2x
```

验证：f(3) = 9, f(3.01) = 9.0601, 差 = 0.0601, 0.0601/0.01 ≈ 6.01 ≈ 2×3

**2. eˣ 的导数**

```
f(x) = eˣ
f'(x) = eˣ
```

特殊情况：eˣ 的导数等于自身。

**3. Sigmoid 的导数**

```
σ(x) = 1 / (1 + e⁻ˣ)
σ'(x) = σ(x) × (1 - σ(x))
```

这是一个优雅的简化——导数可以用函数值本身来表达。

验证：当 σ(x) = 0.8 时，σ'(x) = 0.8 × 0.2 = 0.16。

在 `nn.c` 第 71 行，你可以看到这个公式的精确实现：

```c
// nn.c 第 71 行
case ACT_SIGMOID:
    return activated_output * (1.0 - activated_output);
```

> **检查点**：当 σ(x) = 0.5 时，σ'(x) 是多少？这个值是 Sigmoid 导数的最大值。

### M-03 偏导数

**核心思想：多变量时，一次只盯一个变量变化，其他当常数。**

举例：

```
f(x, y) = 2x + 3y
∂f/∂x = 2   （把 y 当常数，对 x 求导）
∂f/∂y = 3   （把 x 当常数，对 y 求导）
```

∂（读作"偏"，partial）表示"偏导数"。

**对神经网络的意义**：网络有成千上万个权重，每个权重都需要单独求"损失函数对该权重的变化率"。偏导数就是"只看这一个权重，其他冻结"。

> **检查点**：f(x, y) = x²y，∂f/∂x 是多少？∂f/∂y 呢多少？

### M-04 梯度

**梯度 = 所有偏导数组合成的向量，指向函数值下降最快的方向。**

想象你站在一个山坡上，四周各方向都能走：

```
          ↗ 东北方向：上坡（函数值增大）
         ↑
    ← 西北方向：上坡  正北方向：下坡最快
         ↓
          ↘ 西南方向：下坡（函数值减小）

梯度方向 = 正北（函数值下降最快的方向）
负梯度方向 = 正南（函数值增大最快的方向，但我们要减小损失，所以往负梯度方向走）
```

数学表示：

```
∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]    ← 梯度是一个向量
```

**对神经网络的意义**：

```
梯度告诉我们：每个权重应该往哪个方向调、调多少
方向 = 负梯度方向（减少损失的方向）
```

在代码中，梯度不是一次性算出来存成向量的，而是**逐层计算**（反向传播的本质）。但"沿负梯度方向走"这个原则不变。

> **检查点**：为什么我们要"沿负梯度方向"调整权重，而不是"沿梯度方向"？

### M-05 链式法则

**核心思想：复合函数的导数 = 各层导数的乘积。**

用例子最直观：

```
假设：
  u = g(x)       —— x 决定了 u
  y = f(u)       —— u 决定了 y
  那么完整的链是 x → u → y

dy/dx = dy/du × du/dx    （链式法则）
```

具体数字验证：

```
假设 g(x) = x²，f(u) = 2u + 1
取 x = 3：
  u = g(3) = 9
  y = f(9) = 19

du/dx = g'(3) = 2×3 = 6
dy/du = f'(9) = 2
dy/dx = 6 × 2 = 12

直接验证：y = 2x² + 1，dy/dx = 4x，在 x=3 处 dy/dx = 12 ✓
```

**链式法则为什么对神经网络至关重要？**

因为神经网络的损失函数是一个多层嵌套的复合函数：

```
L = 损失(输出)
输出 = 激活(加权和)
加权和 = 权重×输入 + 偏置
```

计算 ∂L/∂权重 时，需要从外到内一层层剥：

```
∂L/∂权重 = ∂L/∂输出 × ∂输出/∂加权和 × ∂加权和/∂权重
            ↑              ↑              ↑
          损失函数        激活函数        线性运算
```

这就是反向传播的核心——**从输出层开始，一层层往回算梯度**。

> **检查点**：如果 y = f(g(h(x)))，dy/dx 怎么算？（提示：dy/dg × dg/dh × dh/dx）

## 第二章 损失函数的数学

### M-06 MSE 的定义和梯度

MSE（Mean Squared Error，均方误差）是回归问题最常用的损失函数。

**定义**：

```
L = (1/n) Σᵢ (ŷᵢ - yᵢ)²
```

其中 ŷ 是预测值，y 是真实值，n 是输出维度。

**对 ŷ 的偏导数**：

```
∂L/∂ŷᵢ = (2/n)(ŷᵢ - yᵢ)
```

推导过程（从 (a-b)² 的导数出发）：

```
(a-b)² = a² - 2ab + b²
对 a 求导：2a - 2b = 2(a-b)
```

**对应到 nn.c**：在 `nn_backward` 函数第 272~278 行：

```c
// nn.c 第 272~278 行
for (int i = 0; i < out_layer->size; i++) {
    double diff = out_layer->out[i] - target[i];     // ŷ - y
    out_layer->error[i] = diff * activate_derivative(...);  // 乘激活函数导数
    loss += diff * diff;                                 // 累积平方误差
}
```

注意：代码里的 `diff * diff` 就是 `(ŷ - y)²`，但 `∂L/∂ŷ = 2(ŷ-y)` 中的系数 2 被省略了——**因为 2 只是一个倍数，不影响"方向"，只影响"步长"**，学习率会吸收这个倍数。

> **检查点**：如果预测值 0.3，真实值 0.7，MSE 的梯度（即调整方向）指向哪里？

### M-07 交叉熵的定义

交叉熵用于分类问题（输出是概率的场景）。

**定义**：

```
L = -Σ yᵢ log(ŷᵢ)
```

其中 y 是 one-hot 编码的真实标签（只有一个 1，其余都是 0），ŷ 是网络输出的概率。

**为什么分类不用 MSE？**

> MSE 在分类问题上会"鼓励"错误的预测值。
>
> 假设真实标签是 [1, 0]（第一个类），网络输出 [0.3, 0.7]：
> - MSE 认为 0.3 不够大，继续推高 → 但 0.7 也不该大，所以产生"拉扯"
> - 交叉熵只关注真实类别的预测值 0.3，不关心其他的 → 更聚焦

在 `nn.c` 第 260~263 行，Softmax + 交叉熵有一个极简化的梯度：

```c
// nn.c 第 260~263 行
out_layer->error[i] = out_layer->out[i] - target[i];  // 直接是 ŷ - y！
loss -= target[i] * log(out_layer->out[i] + 1e-10);    // 加 1e-10 防止 log(0)
```

**为什么误差直接就是 ŷ - y？**

> 这是 Softmax + 交叉熵 的数学巧合：交叉熵对 Softmax 输入的导数恰好简化为 ŷ - y，不需要乘激活函数导数。
> 
> 这就是为什么 Softmax + 交叉熵 成为分类问题的标准组合——计算量更小，梯度更干净。

> **检查点**：第 262 行的 `+ 1e-10` 是在做什么？去掉会怎样？

### M-08 损失函数的梯度指向

关键理解：**梯度的方向告诉我们"该往哪个方向调权重"，梯度的大小告诉我们"该调多少"。**

```
diff = ŷ - y = 0.8 - 0.5 = 0.3    （预测偏大了）
```

这个 0.3 告诉我们：
- **方向**：权重太大了，需要减小（因为预测偏大）
- **大小**：差了 0.3，按这个比例调整

这就是"梯度下降"的直觉——**沿着梯度的反方向走，函数值就会减小。**

```
新权重 = 旧权重 - 学习率 × 梯度
                      ↑
              0.01  ×  0.3  = 0.003
              这个"学习率"控制调整的幅度
```

> **检查点**：如果 diff = -0.2（预测偏小），梯度指向哪个方向？权重应该增大还是减小？

## 第三章 反向传播——核心推导

> 这是进阶版的核心。目标：从数学公式出发，逐行对应到 nn.c 的代码。

### M-09 前向传播的数学表达

前向传播的每一步都是两个操作：**线性变换 + 非线性激活**。

```
第 l 层的计算：
  net[l] = W[l] × out[l-1] + b[l]     ← 线性变换（加权求和加偏置）
  out[l] = f(net[l])                 ← 非线性激活
```

用矩阵写法（`nn.c` 没有用矩阵，是逐元素循环）：

```
        out[0]      W[0][0]  W[0][1]   out_prev[0]     b[0]
net[0] = [net[1]] = [W[1][0]  W[1][1] ] × [out_prev[1]]  + [b[1]]
        net[2]      W[2][0]  W[2][1]   out_prev[2]     b[2]
```

展开第一个元素：

```
net[0] = W[0][0]×out_prev[0] + W[0][1]×out_prev[1] + W[0][2]×out_prev[2] + b[0]
```

**对应 nn.c 第 188~194 行**：

```c
// nn.c 第 188~194 行
double sum = 0.0;
for (int j = 0; j < prev->size; j++) {
    sum += prev->out[j] * cur->weights[i * cur->input_size + j];
}
cur->net[i] = sum + cur->biases[i];
```

其中 `cur->weights[i * cur->input_size + j]` 就是 W[i][j] 的一维数组实现。

> **检查点**：`i * cur->input_size + j` 这个下标计算是怎么把二维矩阵映射到一维数组的？

### M-10 输出层误差 δ

输出层的误差项 δ 定义为：

```
δ_L = ∂L/∂net = (∂L/∂out) × (∂out/∂net) = (∂L/∂out) × f'(net)
```

**对 MSE（回归问题）**：

```
∂L/∂out = 2(ŷ - y)
∂out/∂net = f'(net)

δ_L = 2(ŷ - y) × f'(net)
```

**对 Softmax + 交叉熵（分类问题）**：

```
δ_L = ŷ - y    ← 极简形式
```

**对应 nn.c 第 264~278 行**（回归问题的分支）：

```c
// nn.c 第 272~276 行
double diff = out_layer->out[i] - target[i];     // (ŷ - y)
out_layer->error[i] = diff * activate_derivative(    // × f'(net)
    out_layer->out[i],                              //  ← 已激活的输出值
    out_layer->net[i],                                //  ← 加权和（激活前）
    out_layer->activation);
```

注意 `activate_derivative` 的调用方式：它接收**三个参数**（nn.c 第 68~83 行）：

```c
// nn.c 第 68~83 行
static double activate_derivative(double activated_output, double raw_net, Activation type) {
    switch (type) {
        case ACT_SIGMOID:
            return activated_output * (1.0 - activated_output);  // σ'(x) = σ(x)(1-σ(x))
        case ACT_RELU:
            return raw_net > 0 ? 1.0 : 0.0;                  // ReLU'(x) = 1或0
        case ACT_LINEAR:
            return 1.0;                                        // 常数
        // ...
    }
}
```

**为什么 Sigmoid 的导数这么简单？**

```
σ(x) = 1/(1+e⁻ˣ)

σ'(x) = e⁻ˣ/(1+e⁻ˣ)² = σ(x) × (1 - σ(x))
       ↑            ↑
     σ(x)       1-σ(x)
```

**不需要再算一遍 e⁻ˣ，直接用 σ(x) 的值就能算导数**——这就是为什么 Sigmoid 导数代码只传入 `activated_output`。

> **检查点**：对 ReLU 来说，为什么需要 `raw_net` 而不是只用 `activated_output`？（提示：ReLU 在 x=0 处有一个"拐点"）

### M-11 误差反向传播

从输出层往回，逐层计算每一层的误差 δ：

```
δ[l] = (W[l+1])^T × δ[l+1] ⊙ f'(net[l])
      ↑                    ↑          ↑
    权重转置           后一层误差   激活函数导数
```

展开为代码形式（对第 l 层的第 j 个神经元）：

```
δ[l][j] = Σ_k ( W[l+1][k][j] × δ[l+1][k] ) × f'(net[l][j])
         ↑     ↑                   ↑
        权重  连接关系           本层激活导数
```

含义：
1. 从**后一层的每个神经元**收集误差反馈，乘以它们之间的**权重**
2. 乘以本层的**激活函数导数**（"这个神经元当时有多活跃"）

**对应 nn.c 第 282~298 行**：

```c
// nn.c 第 282~298 行
for (int L = n - 2; L >= 1; L--) {       // 从倒数第 2 层往回
    NNLayer *cur  = &layers[L];              // 当前层
    NNLayer *next = &layers[L + 1];          // 后一层

    for (int j = 0; j < cur->size; j++) {
        double back_sum = 0.0;
        for (int k = 0; k < next->size; k++) {
            // 后一层第 k 个神经元的误差 × 连接权重
            back_sum += next->error[k] * next->weights[k * cur->size + j];
        }
        // 乘以激活函数导数
        cur->error[j] = back_sum * activate_derivative(cur->out[j], cur->net[j], cur->activation);
    }
}
```

**逐行解释**：

| 代码行 | 对应数学 | 含义 |
|--------|---------|------|
| `next->error[k]` | δ[l+1][k] | 后一层第 k 个神经元的误差 |
| `next->weights[k * cur->size + j]` | W[l+1][k][j] | 连接后一层 k 神经元和当前层 j 神经元的权重 |
| `back_sum` | Σ (W × δ) | "从后面传过来的总反馈" |
| `activate_derivative(...)` | f'(net) | 乘以激活函数导数（缩放反馈） |
| `cur->error[j]` | δ[l][j] | 当前层第 j 个神经元的最终误差 |

> **检查点**：如果某层某个神经元的 `out` 值是 0（因为 ReLU 把负数关掉了），它的 `error` 会变成什么？

### M-12 权重梯度

有了误差 δ 之后，权重该怎么调？

```
∂L/∂W[l][i][j] = δ[l][i] × out[l-1][j]
```

**含义**：

- `δ[l][i]`：本层第 i 个神经元"背了多少锅"（误差有多大）
- `out[l-1][j]`：前层第 j 个神经元的"输出有多强"（信号有多活跃）
- 两者相乘 = "这个连接应该调多少"

**直觉**：

> 如果前层输出为 0（这个输入没激活），那调整这个权重也没意义——信号根本没传过来。
> 如果误差很小（预测已经很准了），调整幅度也很小。
> 只有两个条件都满足（信号活跃 + 误差大），权重才会大幅度调整。

**对应 nn.c 第 329~341 行**：

```c
// nn.c 第 329~341 行
double delta = cur->error[i];              // δ[l][i]：误差

for (int j = 0; j < prev->size; j++) {
    double gradient = delta * prev->out[j];  // δ × out：误差 × 前层输出
    cur->weights[i * cur->input_size + j] -= lr * gradient;  // 调整权重
}
```

> **检查点**：如果 `delta = 0`（误差为零），权重会被调整吗？这合理吗？

### M-13 偏置梯度

偏置的梯度更简单：

```
∂L/∂b[l][i] = δ[l][i]
```

没有乘以前层输出，因为偏置不与任何输入相乘。

**对应 nn.c 第 345 行**：

```c
// nn.c 第 345 行
cur->biases[i] -= lr * delta;
```

一行代码，干净利落。

> **检查点**：为什么偏置的梯度比权重简单？（提示：偏置是"常数项"，对输入的偏导数为 0）

### M-14 梯度下降更新

把梯度乘以学习率，减去旧值：

```
新权重 = 旧权重 - 学习率 × 梯度
```

**学习率 lr 的作用**：控制每一步调整的幅度。

```
lr = 0.01：每步调整梯度的 1%
lr = 0.1：  每步调整梯度的 10%（可能太大）
```

**为什么是"减号"？**

> 梯度指向损失增大的方向，我们要**减小**损失，所以要往**反方向**走。

这就像下山：
- 梯度告诉你"北边最陡"（损失增大方向）
- 你要往南走（损失减小方向）
- 所以：`新位置 = 旧位置 - 步长 × 梯度`

**对应 nn.c 第 341 行和第 345 行**：

```c
cur->weights[...] -= lr * gradient;   // 权重更新
cur->biases[i]    -= lr * delta;      // 偏置更新
```

> **检查点**：如果学习率设得很大（比如 10），会发生什么？如果设为 0 呢？

### M-15 一步训练的完整流程

`nn_train_step`（nn.c 第 356~364 行）把所有步骤串起来：

```c
// nn.c 第 356~364 行
double nn_train_step(NeuralNet *nn, double *input, double *target) {
    nn_forward(nn, input, NULL);     // ① 前向传播：计算所有层的 out[]
    double loss = nn_backward(nn, target); // ② 反向传播：计算所有层的 error[]
    nn_update(nn);                  // ③ 权重更新：用 error[] 调整 weights 和 biases
    return loss;                    // 返回本轮损失值
}
```

**数据流图**：

```
input
  ↓
[nn_forward]
  ↓ 把数据写入各层的 out[] 和 net[]
target
  ↓
[nn_backward]
  ↓ 用 target 和各层的 out[]/net[] 计算各层的 error[]
  ↓
[nn_update]
  ↓ 用各层的 error[] 和前层的 out[] 调整 weights[] 和 biases[]
```

## 第四章 激活函数的数学细节

### M-16 Sigmoid 及其导数

```
σ(x) = 1 / (1 + e⁻ˣ)
σ'(x) = σ(x) × (1 - σ(x))
```

**Sigmoid 的特性**：

| x 值 | σ(x) | σ'(x) | 解读 |
|-------|-------|-------|------|
| x = -10 | ≈ 0.000 | ≈ 0.000 | 神经元"关闭"，梯度几乎为 0 |
| x = -5 | ≈ 0.007 | ≈ 0.007 | 几乎关闭，梯度极小 |
| x = 0 | 0.500 | 0.250 | 最大梯度点 |
| x = 5 | ≈ 0.993 | ≈ 0.007 | 几乎完全打开，梯度极小 |
| x = 10 | ≈ 1.000 | ≈ 0.000 | 完全饱和，梯度为 0 |

**核心问题**：当 x 的绝对值很大时（> 5），σ'(x) ≈ 0。

这意味着：如果 Sigmoid 神经元的输入值太极端，它对误差的传递能力几乎为零——**后面的层收不到任何有用的误差信号**。

这就是"梯度消失"的根源之一。

### M-17 ReLU 及其导数

```
f(x) = max(0, x)
f'(x) = 1 if x > 0, 0 if x ≤ 0
```

**ReLU 为什么能缓解梯度消失？**

关键区别：ReLU 在正区间内导数恒为 1，不会因为激活值的大小而衰减。

```
假设连续 3 层都用 ReLU：
  第 3 层梯度 × 1 × 1 = 第 1 层梯度    ← 梯度不会被压缩！
```

而 Sigmoid：

```
假设连续 3 层都用 Sigmoid：
  第 3 层梯度 × 0.25 × 0.25 = 第 1 层梯度 × 0.0625    ← 梯度被压缩到 1/16！
```

5 层之后：0.25⁴ ≈ 0.001，梯度几乎消失。

**ReLU 的代价：死亡神经元**

如果某个神经元的 net 持续为负值，ReLU 的输出永远是 0，梯度永远是 0——这个神经元**永久失活**，无法恢复。

### M-18 梯度消失的数学原因

**多层网络中的梯度传播链**：

```
∂L/∂W[1] = δ[L] × f'[L](z[L]) × W[L] × ... × f'[2](z[2]) × W[2] × f'[1](z[1])
```

如果所有激活函数都用 Sigmoid：

```
|f'[l]| ≤ 0.25  →  5 层后的梯度 ≤ 0.25⁴ ≈ 0.001
```

梯度接近零 → 权重几乎不更新 → 前面的层"学不到东西"。

**对应 nn.c 的实际做法**：

项目代码已经选择了正确的策略——隐藏层用 ReLU（`task_sin.c` 第 47 行、`task_projectile.c` 第 47 行），只在特定位置用 Sigmoid。

> **检查点**：如果你的网络有 10 层 ReLU，梯度还会消失吗？（提示：ReLU 导数为 1 或 0，只要不是全 0 就不会完全消失）

### M-19 Xavier 初始化的数学推导

**目标**：让每一层的输出方差保持稳定，不因网络加深而爆炸或消失。

Xavier 初始化的公式：

```
W ~ N(0, 2 / (n_in + n_out))
```

**推导逻辑（简化版）**：

1. 假设输入 x 的方差为 Var(x)，权重 W 的方差为 Var(W)，输入和权重互相独立
2. 加权和的方差：Var(net) = n_in × Var(W) × Var(x)
3. 要保持方差不变：Var(net) = Var(x) → Var(W) = 1/n_in
4. 但这只是前向传播。反向传播也需要稳定，综合考虑：Var(W) = 2/(n_in + n_out)

**对应 nn.c 第 128 行**：

```c
// nn.c 第 128 行
double scale = sqrt(2.0 / (prev->size + size));
```

- `prev->size` = n_in（输入神经元数）
- `size` = n_out（本层神经元数）
- `sqrt(...)` 是正态分布的标准差

> **检查点**：如果输入层有 2 个神经元，隐藏层有 100 个神经元，权重的初始化幅度是多少？如果反过来呢？

## 第五章 数值稳定性

### M-20 Softmax 溢出问题

Softmax 的计算中涉及 eˣ，当输入值很大时会导致数值溢出。

**解决方案：先减去最大值。**

```
softmax(z_i) = e^(zᵢ - max(z)) / Σ e^(zⱼ - max(z))
```

减去 max 后，最大的指数项变成 e⁰ = 1，其他都 ≤ 1，不会溢出。

**对应 nn.c 第 203~214 行**：

```c
// nn.c 第 203~214 行
double max_val = cur->net[0];
for (int i = 1; i < cur->size; i++)
    if (cur->net[i] > max_val) max_val = cur->net[i];

double sum_exp = 0.0;
for (int i = 0; i < cur->size; i++) {
    cur->out[i] = exp(cur->net[i] - max_val);  // 减去 max 后再取指数
    sum_exp += cur->out[i];
}
for (int i = 0; i < cur->size; i++) {
    cur->out[i] /= sum_exp;                   // 归一化为概率
}
```

> **检查点**：减去 max 后，softmax 的输出值有变化吗？（提示：分母和分子同时缩放了相同的值，结果不变）

### M-21 log(0) 防护

交叉熵中包含 `log(ŷ)`，如果 ŷ = 0 会导致 log(0) = -∞，程序崩溃。

**解决方案：加一个极小值 ε。**

**对应 nn.c 第 262 行**：

```c
loss -= target[i] * log(out_layer->out[i] + 1e-10);  // 1e-10 防止 log(0)
```

`1e-10` 是一个极小的数（0.0000000001），确保 `log` 的参数永远大于 0。

> **检查点**：为什么用 1e-10 而不是 0？（提示：如果用 0，log(0) 仍然是 -∞）

### M-22 梯度裁剪的必要性

当权重初始化不当或学习率太大时，梯度值可能变得非常大（指数级增长）——这就是**梯度爆炸**。

**解决方案：限制梯度的范数不超过阈值。**

```
if ||梯度|| > threshold:
    梯度 = threshold × 梯度 / ||梯度||
```

当前 nn.c 没有实现梯度裁剪（学习率足够小，暂不需要）。但在进阶版的拓展思考中，这是一个需要了解的概念。

**何时会需要梯度裁剪？**

- RNN（循环神经网络）中，梯度沿时间步累乘，容易爆炸
- 学习率设置过大时
- 网络层数很多（>20 层）且权重初始化不当时

## 第六章 回归实战案例——嵌入式传感器应用

前五章从数学角度完整推导了反向传播。本章用两个真实的嵌入式传感器案例，展示这些数学在工程中如何落地。两个案例都是**回归问题**——输出是连续值而非类别，使用 MSE 损失函数和 Linear 输出层。

### M-23 传感器温度补偿

**问题**：NTC 热敏电阻的 ADC 读数受供电电压波动、自发热、非线性误差影响，需要补偿才能得到真实温度。

**物理模型**（`task_temp_comp.c` 中模拟）：

```
真实温度 T ∈ [-20°C, 80°C]

ADC 读数的四个误差来源：
1. 供电电压偏差：Vcc 偏离 3.3V 时，ADC 按比例缩放
2. 自发热效应：传感器自身发热，温度 = 真实温度 + k × (真实温度 - 环境)
3. 非线性误差：温度两端的灵敏度下降（NTC 特性）
4. 随机噪声：高斯分布
```

**为什么不能用简单公式修正？** 因为误差来源之间是耦合的——供电电压的影响取决于温度，自发热取决于温度差和散热条件。简单的线性补偿（y = ax + b）只能修正部分误差。

**神经网络如何解决？** MLP 能自动学习多个输入特征之间的非线性组合：

```
输入(3) → 隐藏(32, ReLU) → 隐藏(16, ReLU) → 输出(1, Linear)
  ↑                              ↑
  ADC值, 参考温度, 供电电压      补偿后的真实温度
```

隐藏层中的 ReLU 激活函数提供了非线性能力——它能将输入空间"折叠"，让线性不可分的数据在高维空间变得线性可分（见 M-10 中误差 δ 的计算）。

**运行方式**：

```cmd

```

**观察重点**：

1. 训练 5000 轮后，Loss 降到多少？（目标：0.01 以下）
2. 验证部分的预测值和真实值差距有多大？换算回温度单位是多少度？
3. 这个案例中，输入 3 个特征各自贡献了什么信息？如果去掉"供电电压"这个输入，预测精度会怎么变化？

### M-24 电池 SOC 估计

**问题**：根据锂电池的端电压、放电电流和温度，估计剩余电量百分比（State of Charge）。

**这是嵌入式 AI 最经典的真实应用之一**。Tesla、比亚迪、宁德时代的 BMS（电池管理系统）都在用神经网络做 SOC 估计。

**为什么 SOC 估计是难题？** 电池的端电压与剩余电量的关系不是简单的线性关系：

```
端电压 V
  ↑
4.2V ┤                    ╱
     │                   ╱ ← 满电区（SOC 90~100%）
3.7V ┤              ─────    ← 平台区（SOC 20~90%）
     │           ╱
3.0V ┤        ╱              ← 空电区（SOC 0~20%）
     └────────────────────→ SOC
     0%                      100%
```

加上电流影响（大电流放电时电压被拉低）和温度影响（低温时内阻增大），关系更加复杂。**传统方案是用查表 + 卡尔曼滤波，需要大量标定工作。神经网络方案只需用数据训练，自动学习这些非线性关系。**

**代码中的物理模型**（`task_battery.c`）：

```c
// OCV-SOC 曲线：开路电压随 SOC 变化
static double ocv_from_soc(double soc) {
    // 三段式：空电快降 → 平台缓降 → 满电快升
}

// 内阻模型：R 受温度和 SOC 影响
static double internal_resistance(double soc, double temp_c) {
    double temp_factor = exp(-0.02 * (temp_c - 25.0));  // Arrhenius 简化
    double soc_factor = 1.0 + 0.5 * (1.0 - soc);        // SOC 越低，内阻越大
    return R_BASE * temp_factor * soc_factor;
}

// 端电压 = OCV - I × R + 噪声
```

**网络结构**：

```
输入(3) → 隐藏(64, ReLU) → 隐藏(32, ReLU) → 隐藏(16, ReLU) → 输出(1, Linear)
  ↑                                                               ↑
  电压, 电流, 温度                                             SOC (0~1)
```

注意这里有 3 个隐藏层——比温度补偿案例更深。因为 OCV-SOC 曲线的非线性程度更高，需要更强的拟合能力。

**运行方式**：

```cmd
train_demo.exe

```

**观察重点**：

1. Loss 的下降模式——和前面的案例比，是更平稳还是更震荡？
2. 验证输出中，SOC 预测误差通常在多少个百分点以内？
3. 对比温度补偿案例（2 层隐藏层）和电池 SOC（3 层隐藏层），更深的网络有什么影响？
