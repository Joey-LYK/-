## 第二章 用比喻理解核心概念

> 核心思路：用生活中的比喻理解抽象概念。不需要数学公式。

### B-04 什么是神经元

**比喻：调音台上的旋钮**

想象一个调音台，上面有一排旋钮。每个旋钮控制一个输入信号的"影响力"：

- 旋钮往右拧 → 这个输入信号的影响变大
- 旋钮往左拧 → 这个输入信号的影响变小
- 旋钮在中间（偏置）→ 即使没有输入信号，也有一个基础输出

一个神经元做的就是这个事情：

```
输入1 ──→ [旋钮w1] ──┐
输入2 ──→ [旋钮w2] ──┼──→ 求和 ──→ [偏置b] ──→ 激活函数 ──→ 输出
输入3 ──→ [旋钮w3] ──┘
```

**用代码验证**：打开 `nn.h`，看第 42~58 行的 `NNLayer` 结构体：

```c
// nn.h 第 42~58 行
typedef struct {
    int input_size;    // 前一层有几个输入
    int size;          // 本层有几个神经元（= 几个"调音台"）

    double *weights;   // 旋钮：每个输入对应一个权重
    double *biases;    // 偏置：即使没有输入，也有基础输出
    double *net;       // 求和结果（激活前）
    double *out;       // 最终输出（激活后）

    Activation activation; // 激活函数类型
} NNLayer;
```

看到没？`weights` 就是旋钮，`biases` 就是零点偏移，`out` 就是最终输出。

> **检查点**：用你自己的话解释：一个神经元在做什么？

### B-05 什么是权重和偏置

**权重 w：信号的放大/缩小器**

权重决定了"某个输入有多重要"。权重越大，这个输入对最终结果的影响越大。

举例：假设你在预测房价，输入有"面积"和"房间数"两个信号。
- 如果面积的权重是 0.8，房间数的权重是 0.1
- 说明面积对房价的影响远大于房间数

**偏置 b：基础输出值**

即使所有输入都是 0，偏置也能让神经元产生输出。它的作用是"调整激活门槛"。

> 比喻：偏置就像温度计的零点校准。零点偏了，所有读数都会偏差。

**用代码验证**：权重是在哪里初始化的？看 `nn.c` 第 128~137 行：

```c
// nn.c 第 128~137 行
double scale = sqrt(2.0 / (prev->size + size));

for (int i = 0; i < w_count; i++) {
    layer->weights[i] = gauss_rand() * scale;  // 随机初始化旋钮
}

for (int i = 0; i < size; i++) {
    layer->biases[i] = 0.0;                     // 偏置初始化为 0
}
```

注意两点：
1. 权重是**随机**的——每个神经元一开始的"旋钮位置"都不一样
2. 偏置初始为 **0**——先从一个公平的起点开始

> **检查点**：为什么权重不能全部初始化为相同的值？（提示：如果所有旋钮一样，所有神经元就做一样的事了）

### B-06 什么是激活函数

**比喻：阈值开关**

想象一扇门，只有当"推力"超过某个阈值时才会打开：

```
推力 = 0    →  门关着，输出 0
推力 = 2    →  门开了，输出 2（等于推力）
推力 = -1   →  门关着，输出 0
```

这就是 ReLU（最常用的激活函数）的直觉：**负数变 0，正数不变**。

为什么需要激活函数？

> 如果没有激活函数，无论堆多少层，网络都等价于"一层"。
> 因为 `线性 + 线性 = 线性`，多层线性变换可以合并成一步。
> **激活函数引入了"非线性"，让网络能学习复杂的弯曲形状。**

**用代码验证**：打开 `nn.c` 第 46~55 行，看激活函数的实现：

```c
// nn.c 第 46~55 行
static double activate(double x, Activation type) {
    switch (type) {
        case ACT_SIGMOID: return 1.0 / (1.0 + exp(-x));  // S 形曲线，输出 0~1
        case ACT_TANH:    return tanh(x);                  // S 形曲线，输出 -1~1
        case ACT_RELU:    return x > 0 ? x : 0;           // 正数通过，负数变0
        case ACT_LINEAR:  return x;                      // 不做变换
        case ACT_SOFTMAX: return x;
        default:          return x;
    }
}
```

五种激活函数，各有用途：

| 激活函数 | 特点 | 常见用途 |
|---------|------|---------|
| Sigmoid | 输出永远在 0~1 之间 | 二分类（输出概率） |
| Tanh | 输出在 -1~1 之间，有正有负 | 需要正负信号的场景 |
| **ReLU** | 正数通过、负数变 0，计算极快 | **隐藏层的首选** |
| Linear | 输入什么输出什么 | 回归问题的输出层 |

> **检查点**：如果把所有激活函数都换成 Linear，网络还能学会 XOR 吗？为什么？

### B-07 什么是前向传播

**比喻：工厂流水线**

前向传播就像一条流水线，数据一层一层地被加工：

```
原材料(输入)
    ↓
[第一道工序：输入层]    →  只是记录原始数据，不做加工
    ↓
[第二道工序：隐藏层1]  →  加权求和 + 激活函数 = 特征提取
    ↓
[第三道工序：隐藏层2]  →  再次加权求和 + 激活函数 = 更高层特征
    ↓
[最后一道工序：输出层]  →  产生最终预测结果
    ↓
成品(预测输出)
```

每一道工序做的事情完全一样：
1. 从上道工序拿到半成品
2. 对每个半成品做**加权求和**（乘以权重再加偏置）
3. 通过**激活函数**（引入非线性）
4. 传给下一道工序

**用代码验证**：打开 `nn.c` 第 173~224 行，看 `nn_forward` 函数：

```c
// nn.c 第 173~224 行（简化标注）
void nn_forward(NeuralNet *nn, double *input, double *output) {
    // ① 输入层：直接把原始输入当作"已激活输出"
    for (int i = 0; i < layers[0].size; i++) {
        layers[0].net[i] = input[i];
        layers[0].out[i] = input[i];
    }

    // ② 从第1层到最后一层：逐层加工
    for (int L = 1; L < n; L++) {
        // 对当前层的每个神经元
        for (int i = 0; i < cur->size; i++) {
            // 加权求和：sum = Σ(前层输出 × 权重) + 偏置
            double sum = 0.0;
            for (int j = 0; j < prev->size; j++) {
                sum += prev->out[j] * cur->weights[i * cur->input_size + j];
            }
            cur->net[i] = sum + cur->biases[i];

            // 激活函数
            cur->out[i] = activate(cur->net[i], cur->activation);
        }
    }

    // ③ 把输出层的 out 复制给调用者
    // ...
}
```

这段代码就是流水线的完整实现：
- 外层循环 `for (int L = 1; ...)` → 遍历每一道工序
- 内层两个循环 → 对每个神经元做加权求和和激活

> **检查点**：用你自己的话描述数据从输入到输出经过了哪些步骤。

### B-08 什么是损失函数

**比喻：考试扣分**

损失函数就是"评分标准"——衡量预测值和真实值差了多少。

我们项目用的是 MSE（均方误差）：

> 把预测值和真实值的差值平方，然后取平均。
> 差值越大，扣分越多；差值越小，扣分越少。

直观理解：

| 预测值 | 真实值 | 差值 | 差值的平方 | 解读 |
|--------|--------|------|----------|------|
| 0.67 | 0.67 | 0.00 | 0.0000 | 完美预测 |
| 0.70 | 0.67 | 0.03 | 0.0009 | 很好的预测 |
| 0.50 | 0.67 | 0.17 | 0.0289 | 还行 |
| 0.00 | 0.67 | 0.67 | 0.4489 | 差得远 |

**为什么要平方？** 因为平方会把"大误差"和"小误差"的差距拉大。差 0.1 的惩罚是 0.01，差 0.5 的惩罚是 0.25——差了 25 倍。

> **检查点**：如果不用平方，直接用差值的绝对值，会有什么问题？（提示：正负误差会互相抵消）

### B-09 网络的创建

创建一个神经网络只需要两步：

```c
// 第一步：创建空网络，设置学习率
NeuralNet *nn = nn_create(0.01);  // 学习率 0.01

// 第二步：一层一层地添加
nn_add_layer(nn, 1, ACT_LINEAR);  // 输入层：1 个输入
nn_add_layer(nn, 16, ACT_RELU);   // 隐藏层：16 个神经元
nn_add_layer(nn, 16, ACT_RELU);   // 隐藏层：16 个神经元
nn_add_layer(nn, 1, ACT_LINEAR);  // 输出层：1 个输出
```

这段代码创建的网络结构是：

```
输入(1) → 隐藏1(16, ReLU) → 隐藏2(16, ReLU) → 输出(1)
```

对照 `nn.c` 的 `nn_add_layer` 函数（第 97~145 行），添加每一层时发生了什么：

1. **输入层**（第一个 `nn_add_layer`）：不创建权重，只分配 `net[]` 和 `out[]` 缓冲区

   - 创建 `biases[]` 偏置向量：`size` 个值

### B-10 权重初始化

为什么权重要随机初始化，而不是全部设为 0？

> 如果所有权重都是 0，那么同一层的所有神经元在每次训练中收到完全相同的信号，产生完全相同的输出，被调整完全相同的量。
> 结果就是：**一万个神经元等于一个神经元**，网络白长了。

Xavier 初始化的核心思想是：

> **让每一层输出的"波动幅度"和输入的"波动幅度"大致相同。**
>
> 这样信号在层层传递时不会越来越大（爆炸）或越来越小（消失）。

对应到代码（`nn.c` 第 128 行）：

```c
double scale = sqrt(2.0 / (prev->size + size));
layer->weights[i] = gauss_rand() * scale;
```

- `prev->size`：上一层有多少个神经元
- `size`：本层有多少个神经元
- 神经元越多，权重初始化的幅度越小——**越大的层越"谨慎"**

> **检查点**：如果所有权重初始化为 0.5（一个固定值），训练会出什么问题？

### B-11 前向传播的计算

我们用具体的数字走一遍前向传播。

假设最简单的网络：2 个输入 → 1 个隐藏神经元（ReLU）→ 1 个输出（Linear）。

```
输入: x = [1.0, 2.0]
权重: w = [0.3, -0.5]
偏置: b = 0.1
```

前向传播步骤：

```
第 1 步：加权求和
    net = 1.0 × 0.3 + 2.0 × (-0.5) + 0.1
        = 0.3 - 1.0 + 0.1
        = -0.6

第 2 步：激活函数 (ReLU)
    out = max(0, -0.6) = 0     ← 负数被"关掉"了

第 3 步：这就是本神经元的输出，传给下一层
```

如果输入是 `[3.0, 1.0]` 呢？

```
    net = 3.0 × 0.3 + 1.0 × (-0.5) + 0.1 = 0.5
    out = max(0, 0.5) = 0.5    ← 正数直接通过
```

**对比**：同样的网络，不同输入产生了完全不同的输出（0 vs 0.5）。这就是权重的威力——它让网络对不同输入做出不同响应。

对应到 `nn.c` 的代码（第 184~198 行）：

```c
for (int i = 0; i < cur->size; i++) {
    // 加权求和
    double sum = 0.0;
    for (int j = 0; j < prev->size; j++) {
        sum += prev->out[j] * cur->weights[i * cur->input_size + j];
    }
    cur->net[i] = sum + cur->biases[i];   // 加上偏置

    cur->out[i] = activate(cur->net[i], cur->activation);  // 激活
}
```

> **检查点**：`cur->weights[i * cur->input_size + j]` 这个下标计算在做什么？为什么不是 `weights[i][j]`？

### B-12 网络结构的设计

怎么决定隐藏层用几层、每层几个神经元？这是神经网络最"玄学"的部分。

**几条经验法则**（都是实验总结出来的，不是数学推导）：

| 场景 | 输入维度 | 隐藏层建议 | 参考项目代码 |
|------|---------|----------|------------|
| 简单函数拟合（sin） | 1 | 2 层 × 16 神经元 | `train_demo.c` 第 163~165 行 |
| 逻辑问题（XOR） | 2 | 1 层 × 4 神经元 | `train_demo.c` 第 173~174 行 |
| 复杂回归（抛体） | 2 | 2 层 × 64/128 神经元 | `train_demo.c` 第 183~184 行 |

规律：
- **输入简单 → 隐藏层小**（sin 只要 1 个输入，2×16 就够）
- **问题复杂 → 隐藏层大**（抛体需要 2×64 + 2×128）
- **输出维度**由任务决定：回归通常是 1，分类等于类别数

> **检查点**：如果想预测 3 个值（比如抛体运动的 x、y 和飞行时间），输出层应该设计成什么样？

### B-15 网络宽度的影响

保持层数不变，修改每层的神经元数量：

| 实验 | sin(x) 每层神经元 | 预期效果 |
|------|-------------------|---------|
| 实验 1 | 4 | 可能学不好——"人手不够"，表达能力不足 |
| 实验 2 | 16 | 正常学会 |
| 实验 3 | 128 | 学得更好，但训练更慢（参数更多） |

参数量计算公式：

```
第 l 层的参数 = (本层神经元数) × (前层神经元数) + (本层神经元数)
```

举例：2 层 × 16 神经元，1 输入 1 输出：
- 第 1 层：16 × 1 + 16 = 32 个参数
- 第 2 层：1 × 16 + 1 = 17 个参数
- 总计：49 个参数

**动手任务**：对比 4 和 128 神经元的训练结果，记录训练时间和最终 Loss。

### B-16 训练轮次的影响

| 实验 | epochs | 预期效果 |
|------|--------|---------|
| 实验 1 | 100 | 可能还没学好 |
| 实验 2 | 1000 | 基本学会了 |
| 实验 3 | 5000 | 默认值，应该收敛得很好 |

>
> 判断方法：如果训练 Loss 持续下降但预测效果变差，就是过拟合了。

**动手任务**：对 sin(x) 任务，用 epochs=100 和 epochs=50000 各跑一次，对比 10 个预测样本的准确度。

### B-17 XOR 的特殊性

XOR 是神经网络的"试金石"——**没有隐藏层就学不会**。

**为什么？**

> XOR 的本质是"非线性可分"问题：
>
> ```
> 输入(0,0) → 输出 0
> 输入(0,1) → 输出 1
> 输入(1,0) → 输出 1
> 输入(1,1) → 输出 0
> ```
>
> 你无法在平面上画一条直线把 0 和 1 分开。
>
> 没有隐藏层 = 纯线性变换 = 只能画直线 = 学不会 XOR。

**动手任务**：修改 XOR 任务的代码，去掉隐藏层（直接 `1 输入层 → 1 输出层`），运行看 Loss 能不能降下来。

在 `train_demo.c` 第 173~175 行：

```c
// 改成没有隐藏层
train_task(&task_xor, 2, NULL, 0, 1, ACT_SIGMOID, 0.1, 2000, 20);
```

## 第五章 实战案例——真实场景初体验

前面的 sin/XOR/抛体运动都是可以用公式精确计算的。但现实中，神经网络最有价值的地方恰恰是处理**无法用公式描述**的问题。本章用两个真实场景案例，让你感受这种差异。

### B-18 环境舒适度分类

**问题**：根据温度和湿度，判断"人体舒适度"——冷、舒适、闷、热。

**为什么这跟 XOR 不同？** XOR 的规则是确定的（0⊕1=1，永远如此）。但"25°C + 65% 湿度"算舒适还是闷？有人觉得还行，有人觉得闷。**规则本身就是模糊的**——没有公式能精确描述。

**打开对应的代码看看**：`task_comfort.c`

```c
// file: docs/example/task_comfort.c

// 数据来源：内置 160 条数据，覆盖 5~40°C × 15~100% 湿度空间
// 每条数据有随机扰动，模拟真实世界的模糊性

static void generate(double *input, double *target) {
    build_dataset();                    // 首次调用时构建数据集
    int idx = rand() % DATASET_SIZE;    // 随机选一条

    input[0] = (dataset[idx][0] - TEMP_MIN) / (TEMP_MAX - TEMP_MIN);  // 温度归一化
    input[1] = (dataset[idx][1] - HUMI_MIN) / (HUMI_MAX - HUMI_MIN);  // 湿度归一化

    for (int i = 0; i < 4; i++) {
        target[i] = (i == labels[idx]) ? 1.0 : 0.0;  // one-hot 编码
    }
}
```

**注意到两个新概念**：

1. **one-hot 编码**：输出不再是 1 个值，而是 4 个值，分别代表 4 个类别。目标类别对应的位置是 1，其余是 0。例如"舒适" = [0, 1, 0, 0]。
2. **Softmax 输出**：输出层用 Softmax 激活函数（见 nn.h:37），它把 4 个输出变成概率分布（总和为 1）。哪个概率最高，就是预测的类别。

**运行方式**：

```cmd
train_demo.exe
# 选择 4. 环境舒适度分类
```

**网络结构**：

```
输入(2: 温度, 湿度) → 隐藏(16, ReLU) → 隐藏(16, ReLU) → 输出(4, Softmax)
```

**观察重点**：

1. 训练完成后，验证部分会显示每个样本的"预测类别"和"真实类别"，以及**准确率**（正确预测的比例）
2. 注意看分类边界——30°C + 70% 湿度，网络把它分到"闷"还是"热"？
3. 尝试多次运行，因为数据有随机扰动，每次训练结果略有不同

> **检查点**：为什么舒适度分类需要 2 个隐藏层，而 XOR 只需要 1 个？（提示：想想分类边界的复杂度）

### B-19 数码管字符识别

**问题**：根据七段数码管各段的亮灭状态，识别显示的数字 0-9。

**现实意义**：仪器仪表、电子秤、充电器等产品大量使用数码管。通过光电传感器自动读取数码管显示内容是常见需求。但传感器不是 100% 准确——可能有段误亮或误灭。神经网络能学会**容忍这类噪声**。

**七段数码管结构**：

```
 ── 段0 ──
|         |
段5      段1
|         |
 ── 段6 ──
|         |
段4      段2
|         |
 ── 段3 ──
```

例如数字"3" = 段0,1,2,3,6 亮，段4,5 灭 = [1,1,1,1,0,0,1]

**打开对应的代码看看**：`task_sevenseg.c`

```c
// file: docs/example/task_sevenseg.c

// 真值表：10 个数字各自的段亮灭模式
static const int segments[10][7] = {
    /* 0 */ {1,1,1,1,1,1,0},  // 除了段6，其余全亮
    /* 1 */ {0,1,1,0,0,0,0},  // 只亮段1和段2
    // ... 省略中间
    /* 8 */ {1,1,1,1,1,1,1},  // 全亮
    /* 9 */ {1,1,1,1,0,1,1},  // 除了段4，其余全亮
};

#define FLIP_RATE  0.10  // 10% 误读率——每段有 10% 概率被翻转

static void generate(double *input, double *target) {
    int digit = rand() % 10;  // 随机选一个数字
    for (int i = 0; i < 7; i++) {
        double val = (double)segments[digit][i];
        if (((double)rand() / RAND_MAX) < FLIP_RATE) {
            val = (val > 0.5) ? 0.0 : 1.0;  // 翻转！
        }
        input[i] = val;
    }
    // ... one-hot 编码 target
}
```

**这个案例的特别之处**：真值表是确定性的——理论上用 if-else 就能判断。但加了 10% 噪声后，if-else 就不好写了。如果段6本该亮但传感器读成灭，这个"3"看起来可能像"9"。神经网络能学会综合判断——即使有一两个段读错，仍然大概率正确。

**运行方式**：

```cmd
train_demo.exe
# 选择 5. 数码管字符识别
```

**网络结构**：

```
输入(7: 段0~段6) → 隐藏(32, ReLU) → 隐藏(16, ReLU) → 输出(10, Softmax)
```

**观察重点**：

1. 训练后的准确率是多少？10% 噪声下能到多少？
2. 看 loss 的下降速度——跟 XOR 比如何？为什么？
3. 想想：如果噪声率从 10% 提高到 30%，准确率会怎么变化？

> **检查点**：如果去掉噪声（FLIP_RATE = 0），网络还能学吗？loss 会降到多少？这说明了什么？
