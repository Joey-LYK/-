# 神经网络教学示例

纯 C 语言实现的教学级神经网络库，包含 9 个由浅入深的训练任务（3 个基础 + 6 个实战案例）。**无任何外部依赖**，只需一个 C 编译器即可编译运行。

## 文件说明

### 核心库

| 文件 | 说明 |
|------|------|
| `nn.h` | 神经网络库头文件 — 层结构定义、激活函数类型、训练 API 声明 |
| `nn.c` | 神经网络库实现 — 前向传播、反向传播、梯度下降、序列化 |

### 基础任务（入门）

| 文件 | 说明 | 难度 |
|------|------|------|
| `task_sin.c` | sin(x) 函数拟合（理解基本训练流程） | ★☆☆ |
| `task_xor.c` | XOR 逻辑门（理解非线性的必要性） | ★☆☆ |
| `task_projectile.c` | 抛体运动落点预测（理解归一化和大数据量） | ★★☆ |

### 实战案例（真实应用场景）

| 文件 | 说明 | 难度 | 类型 |
|------|------|------|------|
| `task_comfort.c` | 环境舒适度分类 — 根据温湿度判断冷/舒适/闷/热 | ★☆☆ | 分类 |
| `task_sevenseg.c` | 数码管字符识别 — 七段数码管 0-9 识别，带噪声容错 | ★☆☆ | 分类 |
| `task_temp_comp.c` | 传感器温度补偿 — ADC 读数非线性校正 | ★★☆ | 回归 |
| `task_battery.c` | 电池 SOC 估计 — 根据电压/电流/温度预测剩余电量 | ★★☆ | 回归 |
| `task_gesture.c` | 手势动作识别 — IMU 加速度统计特征分类 | ★★★ | 分类 |
| `task_voice.c` | 语音命令识别 — 模拟 MFCC 特征的多命令分类 | ★★★ | 分类 |

| `train_demo.c` | 主程序 — 交互式菜单，选择任务后训练并输出结果 |

## 环境要求

- **操作系统**：Windows（程序使用了 `windows.h` 设置控制台编码）
- **编译器**：以下任一即可
  - MSVC（Visual Studio 开发者命令行）
  - GCC / MinGW（如 Code::Blocks 自带或独立安装）

## 编译

### 方式一：MSVC（Visual Studio）

打开 **"x86 Native Tools Command Prompt"**（Visual Studio 开始菜单中），执行：

```cmd
cl /nologo /W4 train_demo.c nn.c ^
  task_sin.c task_xor.c task_projectile.c ^
  task_comfort.c task_sevenseg.c task_temp_comp.c ^
  task_battery.c task_gesture.c task_voice.c
```

### 方式二：GCC / MinGW

```cmd
gcc -Wall -O2 train_demo.c nn.c \
  task_sin.c task_xor.c task_projectile.c \
  task_comfort.c task_sevenseg.c task_temp_comp.c \
  task_battery.c task_gesture.c task_voice.c \
  -o train_demo.exe -lm
```

> - `-lm` 用于链接数学库（`sin()`、`exp()` 等函数）
> - `-O2` 开启优化，加快训练速度
> - MinGW 通常需要通过 Code::Blocks 或 MSYS2 安装

## 代码结构概览

```
Task（任务层）                      NeuralNet（网络层）
┌──────────────────┐               ┌──────────────────┐
│ .generate()      │──→ 数据 ──→   │ nn_forward()     │ 前向传播
│  生成训练样本     │               │ nn_backward()    │ 反向传播
└──────────────────┘               │ nn_update()      │ 权重更新
                                    │ nn_train_step()  │ 训练一步
                                    └──────────────────┘
```

- **Task** 是数据生成器，通过 `generate()` 函数产生 (输入, 期望输出) 训练样本
- **NeuralNet** 是神经网络本身，支持前向传播、反向传播、梯度下降更新
- 每个任务文件只需实现一个 `Task` 结构体即可，无需关心网络内部

## 二次开发：编写自己的任务

按照 `task_sin.c` 的模式，创建一个新文件即可：

```c
#include "nn.h"
#include <stdlib.h>

static void generate(double *input, double *target) {
    // 在这里生成一对 (输入, 期望输出)
    input[0]  = ...;
    target[0] = ...;
}

Task task_my_task = {
    .name       = "我的自定义任务",
    .input_dim  = 1,    // 输入维度
    .output_dim = 1,    // 输出维度
    .generate   = generate,
};
```

然后在 `train_demo.c` 的菜单和 `switch` 中加入新选项，编译时多链接一个 `.c` 文件即可。

## 注意事项

- 训练速度取决于 CPU 性能和任务复杂度，高级案例（任务 7-9）可能需要数十秒到数分钟
- 每次运行程序权重会随机初始化，训练结果会有轻微差异
- 若控制台中文显示乱码，请确保使用 UTF-8 编码的终端（Windows Terminal / VS Code 终端）
- 实战案例的数据基于物理模型/统计模型生成，编译即可运行，无需外部数据文件
